## Default Permission

Allows every media player command.

#### This default permission set includes the following:

- `allow-subscribe`
- `allow-load`
- `allow-play`
- `allow-pause`
- `allow-seek`
- `allow-stop`
- `allow-set-volume`
- `allow-snapshot`
- `allow-media-info`
- `allow-cover-art`
- `allow-waveform`
